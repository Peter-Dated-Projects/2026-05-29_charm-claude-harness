# Repository agent routing

Follow the repository's canonical policy in `docs/repository/agent-policy.md`.

- Start with `docs/repository/index.md` and the nearest manifest only when the task crosses a documented boundary or local patterns are unclear.
- Do not preload all repository documentation. Route the task, load the smallest relevant set, and confirm authorization, data, API, and migration claims in current code.
- Keep changes focused, follow local conventions, run the relevant verification, and update or explicitly review affected documentation before handoff.
- Treat generated files as outputs; change their source template or canonical policy rather than hand-editing them.
