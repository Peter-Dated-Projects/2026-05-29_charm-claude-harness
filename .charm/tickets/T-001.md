## Background

The `test-alpha` worktree was created to demonstrate the harness's ability to run
isolated changes in parallel git worktrees. A single comment line was added to
`src/upper.js` inside that worktree as a minimal, observable change to prove the
isolation mechanism works end-to-end without affecting the main branch.

## Acceptance criteria

- [ ] `.charm/worktrees/test-alpha/src/upper.js` ends with exactly:
      `// test-alpha: added a comment to upper.js for worktree demo`
- [ ] All other lines in that file are identical to `src/upper.js` on main
- [ ] `src/upper.js` on main does NOT contain the comment (change is isolated to
      the worktree)
- [ ] No other files in the worktree differ from the main branch baseline

## Edge cases and failure modes

- Comment present but with different casing, whitespace, or wording: fails the
  exact-match check and the worker must flag the discrepancy.
- Comment accidentally applied to main-branch `src/upper.js` instead of (or in
  addition to) the worktree copy: the isolation invariant is broken.
- Additional unintended changes introduced alongside the comment (whitespace
  normalization, import tweaks, etc.): worker must list every diff, not just the
  comment line.
- Worktree missing or detached from the expected branch: worker should report
  blocked rather than guessing.

## Verification note (reviewer)

Checked at review time: `.charm/worktrees/test-alpha/src/upper.js` contains the
comment as its final line, exact match. Main-branch `src/upper.js` does not have
it. No other changes are present in that file. The worktree is healthy.
