SPECIFIC ADDITIONS:
1. Worktree dependency-sharing preflight: on first `charm start` in a repo (and on worktree creation), detect heavy gitignored dep dirs (node_modules, .venv/venv, Rust target/, build caches like .next/dist/vendor). LOCKFILE-AWARE: symlink-share a dir to main ONLY when the worktree's lockfile hash matches main's (package-lock/yarn.lock/pnpm-lock/Cargo.lock/uv.lock); if a branch changed deps, install locally instead (sharing would corrupt it). Rust target/ is opt-in (rebuild thrash + cargo lock contention). Prompt the operator once for which dirs to share, persist the choice to a shared config in main `.charm`, auto-apply to future worktrees.

3. Single-daemon / single-.charm bootstrap: one daemon in main owns the single .charm; worktree agents reach it via env (e.g. CHARM_SOCK), not relative `.charm/` paths; durable writes (tickets/kb/proposals) go through MCP to that daemon. Reflect this in the auto-detect/bootstrap flow.
