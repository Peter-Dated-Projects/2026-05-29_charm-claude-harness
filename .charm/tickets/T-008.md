## Context
The audit in `.charm/kb/audit-existing-docs.md` found two accuracy bugs in `docs/developing/build.md` that would cause a new user following the install instructions to hit "command not found".

## Tasks
1. **Binary name error.** The install example uses `charm-claude init && charm-claude start "..."`. The installed command is `charm` (not `charm-claude`) — `frieren.sh install` renames the binary when placing it at `~/.local/bin/charm`. Replace every occurrence of `charm-claude` in install/usage examples with `charm`.
2. **Missing `charm-graph` in build output table.** The quick-build output list (`bun run build → dist/charm-claude, dist/charmd, dist/charm-mcp, dist/charm-console`) omits `charm-graph`. Add it.

## Verification
After editing, check: (a) no remaining `charm-claude` references in the usage/install sections; (b) the binary list includes all five binaries: charm, charmd, charm-mcp, charm-console, charm-graph.
