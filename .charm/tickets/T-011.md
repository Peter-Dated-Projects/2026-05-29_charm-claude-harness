## Context
The audit identified that worktrees are completely undocumented for operators, while the README and architecture doc actively deny they exist. This is the highest-severity gap: an orchestrator agent reading the docs would never discover the `create_worktree` tool exists.

## Tasks
Create `docs/operating/worktrees.md` as a new file. Content to cover:

1. **What worktrees are in charm's context.** An opt-in orchestrator-side tool for running isolated parallel lines of work on separate branches, distinct from the default shared-tree model. Not the default; used when work truly cannot share a tree.

2. **When to use worktrees vs. the shared-tree model.**
   - Default: shared tree with file-scope locking (`touches:` in frontmatter) + COORDINATION.md. Use this for most work.
   - Worktrees: when two lines of work need different branches (e.g., a Graphite stack, a hotfix alongside a feature, or work the orchestrator wants to isolate from main). The daemon serializes overlapping scopes on the shared tree; worktrees are an escape hatch when branch isolation is required.

3. **How to open a worktree.** Orchestrator uses `create_worktree` MCP tool: provide a name and base branch. The worktree is created under `.charm/worktrees/<name>/` on a new branch. Reference `docs/developing/mcp-tools.md` for the full tool spec.

4. **Working inside a worktree.** The `EnterWorktree` / `ExitWorktree` tools let an agent scope its cwd to the worktree. Agents in a worktree work on an isolated checkout and cannot see the shared tree's in-flight changes.

5. **Closing a worktree.** The orchestrator is responsible for calling `close_worktree` for every worktree it opens, after the work is merged or abandoned. Orphaned worktrees accumulate disk usage and confuse future sessions.

6. **Checking open worktrees.** `list_worktrees` shows all open worktrees for the current session.

Write in the same style and tone as the existing `docs/operating/` files. After creating the file, add a link to it in `docs/README.md` under the Operating section.
