## Goal
Investigate how similar tools (multi-agent orchestration, workflow engines, parallel task runners) document their concepts. This research feeds into updating charm's docs.

## Tasks
1. WebSearch for documentation from tools like: Temporal, Airflow, Prefect, Ray, Celery, and any AI multi-agent frameworks (CrewAI, AutoGen, LangGraph).
2. Focus specifically on:
   - How they explain orchestration concepts to new users (pipeline stages, workers, tasks, gates)
   - How they document the mental model (diagrams, analogies, progressions)
   - How they structure conceptual vs how-to vs reference content
   - How they handle the 'operators' vs 'developers' audience split
3. Note what charm's README already does well in this regard, and where the existing docs diverge from these patterns.

## Output
Write your findings to `.charm/kb/research-orchestration-doc-patterns.md`. Structure it as:
- How leading tools handle orchestration concept explanation
- Mental model documentation patterns (diagrams, analogies)
- Audience-split strategies
- Gap analysis: what charm's current docs are missing vs these patterns

Do NOT edit any files under docs/ — that is the implementation swarm's job.
